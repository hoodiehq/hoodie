🚀 Getting Started with Hoodie

  1. Create a public folder – Start by creating a public folder in your project root.
  2. Add index.html – Create your index.html inside the public directory.
  3. Include Hoodie – Add this line just before your closing </body> tag:
    <script src="/hoodie/client.js"></script>
    This enables Hoodie methods in your JavaScript files.
  4. Organize your assets – Create folders for your CSS and JavaScript files.
  5. Restart the server – Restart Hoodie to serve assets from your public folder.
