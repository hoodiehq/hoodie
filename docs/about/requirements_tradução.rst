Requisitos
============

Before you start working with Hoodie, here’s what you need to know
regarding your development/server environment and the browsers Hoodie
will run in.

Requisitos de sistema do Hoodie Server
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

-  Mac OSX
-  Windows 7 and up
-  Linux (Ubuntu, Fedora 19+)

Navegadores compatíveis
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

-  Firefox (29+)
-  Chrome (34+)
-  Desktop Safari (7+)
-  Internet Explorer 10+
-  Opera (21+)
-  Android 4.3+
-  iOS Safari (7.1+)

**Importante**: Essa lista é baseada em `PouchDB’s
requirements`_

.. _PouchDB: https://pouchdb.com/learn.html#browser_support
.. _PouchDB: https://pouchdb.com/learn.html
