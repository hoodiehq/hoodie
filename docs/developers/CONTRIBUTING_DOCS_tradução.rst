Contribuindo com a documentação ========================================== Este guia descreve como realizar alterações na documentação do Hoodie. 

Fazendo pequenas alterações 
--------------------
Adoramos pequenas contribuições; caso encontre pequenos erros ou queira sugerir adições, sinta-se à vontade para solicitar uma alteração. Cada página da `documentação do Hoodie <http://hoodie.readthedocs.io/>`_ possui um botão "Edit on GitHub" (Editar no GitHub) no canto superior direito; utilize-o para realizar suas alterações. A documentação do Hoodie utiliza o formato `reStructuredText <http://docutils.sourceforge.net/docs/ref/rst/restructuredtext.html>`_. Embora possa não ser familiar para você, esse formato oferece recursos avançados, úteis para documentações complexas. O editor do GitHub é bastante básico. Se precisar de mais ferramentas de edição, tente copiar e colar o conteúdo neste `editor <http://rst.ninjs.org/>`_ online. Em seguida, você pode realizar um "commit" e criar um "pull request" no GitHub. O "pull request" passará por testes automáticos de gramática, estilo e erros ortográficos comuns. Suas alterações serão, então, revisadas por um administrador do Hoodie, que poderá sugerir modificações. Consulte o `Guia de Estilo de Documentação <DOCS_STYLE.html>`__ para obter orientações sobre a escrita e mais informações sobre os testes.

Fazendo grandes mudanças
------------------

Para alterações significativas, siga as `diretrizes de contribuição do Hoodie para novos colaboradores <CONTRIBUTING.html#for-new-contributors>`__. Isso permite que você compile e teste a documentação localmente — por exemplo, ao adicionar, mover ou atualizar vários documentos. O arquivo `index.rst`, localizado na pasta `docs/`, controla a ordem em que os documentos são exibidos nas páginas da documentação. Lembre-se de atualizar esse arquivo caso tenha removido, adicionado ou deseje reorganizar os documentos. Para compilar a documentação localmente, é necessário instalar o `Python 2.7+ <https://www.python.org/downloads/>`_. Em seguida, instale dois pacotes via `pip`: `Sphinx <http://www.sphinx-doc.org/en/stable/>`_ e `sphinx_rtd_theme <https://pypi.python.org/pypi/sphinx_rtd_theme>`_. ``sudo pip install sphinx`` ``sudo pip install sphinx_rtd_theme`` Acesse o diretório `..hoodie/docs/` ``make html`` | Se você estiver utilizando o Windows PowerShell, observe que há uma pequena diferença no procedimento: ``pip install sphinx`` ``pip install sphinx_rtd_theme`` Antes de executar o comando `make html`, certifique-se de ter instalado o `make <http://gnuwin32.sourceforge.net/packages/make.htm>`_ no Windows, caso ainda não o tenha feito. Você também pode consultar este `link <http://stackoverflow.com/questions/12881854/how-to-use-gnu-make-on-windows>`_ no Stack Overflow para obter mais orientações. Agora, acesse o diretório `..hoodie/docs/` ``make html`` | Após a compilação, os documentos atualizados estarão disponíveis no subdiretório `docs/_build/html`. Basta abrir qualquer arquivo `.html` para visualizar o conteúdo no seu navegador. `Entre em contato <http://hood.ie/contact/>`_ caso tenha dúvidas ou queira contribuir com a documentação do Hoodie.
